## Описание работы
В рамках лабораторной работы №3 выполнены следующие задачи:
1. **Навигация (Flexbox):** Добавлено адаптивное меню в шапке сайта.
2. **Карточки «Книги на полке» (Flexbox):** Создана секция с семантическими тегами `<article>` и обложками книг. Адаптируется под разные экраны (3 / 2 / 1 в ряд).
3. **Галерея «Цитаты недели» (Grid):** Реализована сетка с помощью CSS Grid из 3 элементов на базе тегов `<blockquote>`.
4. **Адаптивная верстка:** Добавлены медиа-запросы `@media` для планшетов и мобильных устройств, исключена горизонтальная прокрутка.

## Запуск
Открыть `index.html` в браузере.
* `index.html` — основная разметка страницы
* `assets/css/style.css` — стили, переменные, Flexbox, Grid и медиа-запросы
* `assets/images/` — изображения обложек книг и личное фото
